# Portfolia

React + Vite portfolio generator frontend. Ready for Vercel deployment.

## Run locally

```bash
npm install
npm run dev
```

## Deploy to Vercel

1. Upload this project to a GitHub repository.
2. In Vercel, choose **Add New → Project** and import the repository.
3. Keep the build command as `npm run build` and output directory as `dist` (Vercel can detect these automatically).
4. Click **Deploy**.

The `vercel.json` file includes SPA routing for React.

## Important

This is the frontend only. Sign-in, admin permissions, saved data, live AI, payments and publishing still need a backend. Do not put secret API keys in frontend code.
